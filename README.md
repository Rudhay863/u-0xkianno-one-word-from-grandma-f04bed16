A tiny Node program that writes the single word a grandma would text about AI — "Whatchamacallit" — to `/output/entry.txt`. It picks the word by scoring a shortlist of grandma gadget-words on the judge's own criteria: grandma voice first, then funny, then tied to machines, then fresh.

## Run it

```sh
node main.ts
```
